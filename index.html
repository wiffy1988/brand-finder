云端同步

品牌、淘货和照片存在 Supabase。你和助手改同一份数据，换手机打开同一网址即可。

首次使用前请在 Supabase SQL Editor 运行仓库里的 supabase-schema.sql。

备份与恢复（可选）

云端已经是主数据源。导出 JSON 可做额外备份；导入会覆盖云端全部数据。
