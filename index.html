Gemini API 密钥

在 Google AI Studio 用 Google 账号登录，点 “Create API key” 获取。密钥只保存在这台手机上，不会上传到任何别的地方。

模型

Google 免费层目前只有 Gemini 2.5 系列能用联网搜索（每天约 500 次），而且 2.5 只对“以前用过的账号”开放。新账号如果 2.5 用不了，可以开通付费（Gemini 3 系列每月前 5000 次搜索免费），或者用“不联网”模式只识别品牌。具体以 Google 官网为准。

测试连接

用一个很小的问题测试密钥和各模型能不能联网，会消耗几次免费额度。
